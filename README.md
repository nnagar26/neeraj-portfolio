# Neeraj Nagar — Portfolio

Personal portfolio website highlighting my experience, education, projects, research, and achievements.

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/nnagar26/neeraj-portfolio.git
cd neeraj-portfolio
open index.html
```

## Features

- Responsive design
- Light and dark themes
- Smooth animations
- Accessible keyboard navigation
- Downloadable résumé
